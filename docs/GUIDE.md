# LÜMEN простыми словами

## Что это

LÜMEN — программа, которая читает техническое задание и, как опытный аналитик, ищет в нём ошибки: размытые слова,
противоречия, пропуски, проблемы API. На выходе — отчёт с цитатами и номерами строк, вердикт «можно ли начинать
разработку» и вопросы, которые надо задать заказчику.

## Из чего состоит (кто за что отвечает)

| Часть | Файлы | Что делает простыми словами |
| :--- | :--- | :--- |
| Читалка документов | `lumen/parsing/` | Открывает PDF, Word, Markdown, TXT, HTML, RTF, фото; превращает в пронумерованные строки |
| Нарезчик требований | `lumen/engine/extractor.py` | Делит документ на отдельные требования, берёт их номера (Ф-1) или даёт свои (REQ-001) |
| Правила | `lumen/engine/rules.py` | Находит ошибки без ИИ: «быстро», «и/или», тиыны/тенге, GET вместо PUT, пустые поля |
| Проверка цитат | `lumen/engine/evidence.py` | Сверяет каждую цитату ИИ с документом — не даёт ИИ выдумывать |
| ИИ-слой | `lumen/llm/` | Общается с Claude / Gemini / другими моделями по строгим шаблонам ответа |
| Дирижёр | `lumen/engine/pipeline.py` | Запускает 15 этапов по порядку, параллелит запросы к ИИ, собирает результат |
| Финтех-эксперт | `lumen/engine/fintech.py` | Проверяет банковские риски: повторные платежи, возвраты, валюты, доступ |
| Оценщик | `lumen/engine/scoring.py` | Считает индекс качества и ставит вердикт READY / NOT READY |
| Генератор отчётов | `lumen/report/` | Пишет отчёт в Markdown, HTML, PDF, Word, Excel, JSON |
| Командная строка | `lumen/cli.py` | Запуск одной командой — так сдаём хакатон |
| Сервер (API) | `lumen/api/app.py` | Принимает файлы из сайта, показывает прогресс, отдаёт отчёты |
| Очередь анализов | `lumen/service.py` | Запускает анализ в фоне, чтобы сайт и бот не зависали |
| Хранилище | `lumen/storage/store.py` | Сохраняет историю: в файлы или в Supabase, с шифрованием |
| Безопасность | `lumen/security.py` | Шифрование, проверка файлов, лимиты запросов, защитные заголовки |
| Telegram-бот | `lumen/bot/telegram.py` | Принимает файлы в чате, присылает отчёт, отвечает на вопросы |
| Демо | `lumen/demo.py`, `examples/` | Показ без ключа ИИ на своём примере |
| Сайт | `web/` | Панель LÜMEN Intelligence: загрузка, линза документа, граф, вопросы |
| Тесты | `tests/` | 45+ автопроверок, что ничего не сломалось |
| Деплой | `Dockerfile`, `railway.json`, `supabase/` | Как запустить в интернете и создать таблицу в базе |

## Зачем нам база данных (Supabase)

Диск сервера на Railway временный: при каждом обновлении или перезапуске всё, что лежало в файлах, стирается.
Без базы LÜMEN работает, но история проверок, ответы на вопросы и ссылки из бота пропадали бы после каждого
деплоя. Supabase — это Postgres в облаке: история хранится постоянно (в зашифрованном виде), а панель может
показывать динамику качества документа между версиями. Если Supabase недоступен, LÜMEN сам переключится на
локальное хранилище и продолжит работать.
