# Лимит на переводы между своими счетами

## Общие сведения

| Параметр | Значение |
| --- | --- |
| Версия | 1.2 |
| Дата | 10.11.2026 |
| Автор | Отдел платёжных продуктов |
| Приоритет | все требования обязательные (must have) |
| Согласующие | Руководитель продукта, архитектор, QA-лид |

## Термины

* **Перевод** — операция списания со счёта клиента с зачислением на другой его счёт, получившая статус COMPLETED.
* **Дневной лимит** — максимальная сумма переводов клиента за календарные сутки (граница суток — в F-4).

## Функциональные требования

* **F-1.** Клиент задаёт дневной лимит целым числом в тиынах от 100 000 до 100 000 000 включительно.
* **F-2.** Система должна отклонить перевод, если сумма переводов клиента за сутки вместе с новым переводом превысит дневной лимит.
* **F-3.** При отклонении система должна вернуть код ошибки LIMIT_EXCEEDED и остаток лимита в тиынах.
* **F-4.** Сутки начинаются в 00:00:00 по времени UTC+5 (Asia/Almaty) по метке времени создания перевода.
* **F-5.** Изменение лимита вступает в силу для переводов, созданных после сохранения настройки.

## Нефункциональные требования

* **NF-1.** Проверка лимита должна завершаться за 200 мс для 99% запросов при нагрузке 500 запросов в секунду, от получения запроса до ответа.

## API

| Параметр | Значение |
| --- | --- |
| REST type | POST |
| Description | Сохранение дневного лимита клиента |
| Request URL | /limits/daily |
| Content-Type | application/json |

| Поле | Тип | Обязательно | Описание |
| --- | --- | --- | --- |
| clientId | string | Да | Идентификатор клиента |
| amount | integer | Да | Лимит в тиынах |

Ответы:

* 200 OK — лимит сохранён, тело {"amount": 500000}.
* 400 Bad Request — сумма вне допустимого диапазона, тело {"code": "VALIDATION_ERROR"}.
* 401 Unauthorized — сессия клиента недействительна.

## Критерии приёмки

* Исходные условия: лимит 1 000 000 тиынов, переводов за сутки нет. Действие: перевод 600 000 тиынов. Ожидаемый результат: перевод выполнен.
* Исходные условия: лимит 1 000 000 тиынов, за сутки переведено 600 000 тиынов. Действие: перевод 500 000 тиынов. Ожидаемый результат: ошибка LIMIT_EXCEEDED, остаток 400 000 тиынов.
