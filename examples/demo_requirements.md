# Перевод по номеру телефона (ДЕМО)

Демонстрационный документ LÜMEN. Содержит намеренно внесённые дефекты для показа работы агента.

## Общие сведения

| Поле | Значение |
| :--- | :--- |
| **Наименование задачи** | Перевод по номеру телефона |
| **Продукт** | Мобильный банк (демо) |
| **Версия** | 0.3 |

## Цели
Клиент переводит деньги другому клиенту банка по номеру телефона без ввода реквизитов карты.

## Функциональные требования
* **FR-1.** Клиент вводит номер телефона получателя в формате +7XXXXXXXXXX и сумму перевода.
* **FR-2.** Система быстро находит получателя и показывает его имя и первую букву фамилии.
* **FR-3.** Максимальная сумма одного перевода — 500 000 ₸.
* **FR-4.** Комиссия не взимается при сумме переводов до 1 000 000 ₸ в месяц.
* **FR-5.** После подтверждения перевода по SMS-коду деньги списываются со счёта отправителя и зачисляются получателю.
* **FR-6.** Система должна использовать PostgreSQL 16 и Kafka для хранения переводов.

## Нефункциональные требования
* **NFR-1.** Сервис должен быть надёжным и выдерживать высокую нагрузку.
* **NFR-2.** Перевод выполняется не более чем за 3 секунды.

## Критерии приемки

| Исходные условия | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| Баланс 700 000 ₸ | Перевести 600 000 ₸ | Перевод выполнен |
| Получатель не найден | Ввести номер | Сообщение «Получатель не найден» |
